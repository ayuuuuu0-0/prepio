# Fonts

Self-hosted so builds never depend on Google Fonts. Latin subsets only, loaded with `next/font/local` in `src/app/layout.tsx`.

| File | Family | Weights | Source |
|---|---|---|---|
| `sora-latin-wght-normal.woff2` | Sora (display) | variable 100–800 | `@fontsource-variable/sora` 5.3.0 |
| `manrope-latin-wght-normal.woff2` | Manrope (body) | variable 200–800 | `@fontsource-variable/manrope` 5.3.0 |
| `ibm-plex-mono-latin-{400,500,600}-normal.woff2` | IBM Plex Mono | 400, 500, 600 | `@fontsource/ibm-plex-mono` 5.3.0 |
